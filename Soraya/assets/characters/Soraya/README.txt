Placeholder frames — replace them.
=================================

Drop your own PNGs into these folders, same names, same counts.
Delete a file and re-run scripts/make_placeholders.py to get it back.

The only rule that matters: keep the character's FEET at the same
height in every frame of every clip (360 of 368 pixels here).
If the feet move between clips she appears to hop when the clip
changes, and no amount of code can fix that afterwards.

Transparent background. Any canvas size works as long as it is the
same for every frame in the pack.
